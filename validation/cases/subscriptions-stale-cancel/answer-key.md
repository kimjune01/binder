# Answer key: stale cancellation approval

## Correct first decision

Request more evidence. The supplied candidate test is relevant and the code
change directly checks an incarnation value, but the control material does not
show that an equivalent observation exposes the audited baseline.

## Seeded issue

The missing base witness. “A regression test passes on the fix” is weaker than
“the check refutes the exact base and stands on the exact candidate.” Binder's
declared rule requires the latter and therefore returns `no-verdict`.

## Narrow claim boundary

The evidence concerns one stale immediate-cancellation approval, one PDA reuse
scenario, exact source revisions, and the named empirical engine. It does not
prove the program or deployment safe.

## What strong comprehension sounds like

> The head test shows that an approval carrying the old period-start value is
> rejected after re-subscription. I still need the same scenario against the
> audited baseline before the declared base-refuted/head-stood rule can warrant
> the claim. Even then, the result is scoped to this replay scenario and these
> revisions.

Do not require these exact words. Score whether the participant identifies the
missing contrast and avoids broadening the conclusion.
